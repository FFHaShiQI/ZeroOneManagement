#### 安装教程

1.  点击克隆/下载
2.  点击下载zip
3.  下载好后将zip文件解压到一个不带中文不带空格的路径下

#### 使用说明
后端:
1.使用IDEA打开后端项目backend
2.注意使用jdk版本17,加载maven依赖
3.在application.yml中修改数据库配置(用户名,密码,数据库名)
前端
1.  前端使用vscode/trae 等编译器
2.  打开前端项目frontend下的ZeroOneManagement项目(注意打开的是ZeroOneManagement文件夹而不是frontend文件夹)
3.  然后终端运行npm install(需要提前下载好node.js)
4.  在终端运行npm run dev启动前端页面
